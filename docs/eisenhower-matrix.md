# MyJournal - Eisenhower Matrix

## Do (Urgent + Important) - MVP
- Setting up customizable journal sections.
- Receiving user input and putting it into the journal.

## Schedule (Not Urgent + Important) - V2.0+
- Formatting journal entries to look organized.
- Allowing the user to pick his or her own font so that each entry feels more personalized.

## Delegate (Urgent + Not Important) - Use Existing Tools
- Java's `java.time` package to obtain dates and times.
- Git and GitHub to manage source code and track development progress.

## Delete (Not Urgent + Not Important) - Cut It
- Mandatory templates that restrict users to predefined sections.
- Automatic "good job" messages at the end of journal entries.
- Excessive pop-ups asking users to make formatting decisions.
