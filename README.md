## Goal
The goal of this project is to create a journal that a person can use to track his or her feelings and thoughts throughout the day. With the mental health crisis only getting worse and worse, more and more people are becoming emotionally numb. This program will provide a template that acts as a guide for when the user is unsure on what to write about, and the program will also give the user the option to just write from a clean text file. Whenever the user is done writing, it will save that entry. 

## MVP Scope
- A template with appropriate categories for the user to write about (feelings, thoughts, meals, activities, etc.)
- A way to track the date and correctly date the journal entry.
- Correctly store the user's journal entry after they are done writing.
- Correctly received input from the reader and puts it onto a .txt file and formats it the way that the user wants it to be formatted.

## Future Plans
- Figuring out the specifics on the formatting of the template (font size, font, etc.)
- Allowing the user to pick his or her own font so that the journal entries feel more personalized.

## Tech Stack
